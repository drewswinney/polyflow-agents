4More than one agent

One agent at a time: the app scopes entirely to whoever is selected, and you switch by tapping the name in the header. Nothing spans agents — no merged queue, no combined spend — so each one keeps its own sessions, settings, and history. Since a non-Hermes agent won't have skills, cron, or MCP, the Settings list is built from what the connected agent reports rather than a fixed menu.

4aTapping search expands the field in place on the Sessions page, labelled with the agent it searches, since results only ever come from the selected one. The agent sits centered in every header, so the one you are acting on is never off-screen, and each carries its own icon. Closed it reads as the status line you already had; open it's a short list with live state, so you know what you're switching into before you commit.
